# Creative entry and interaction design

User-requested visual extension, 2026-09-12. The supplied reference established warm neutral surfaces, restrained type, saturated red/amber artwork and strong visual hierarchy. The entry uses an original sculptural image; no reference screenshots, text, photos or logos are copied. The signed-in studio keeps its established dark review surfaces.

## Sources applied
- [Appllama app design skill](https://github.com/Appllama/appllama-skills/blob/main/skills/appllama-app-design-skill/SKILL.md): consistent hierarchy, semantic/native controls, stable review data, purposeful motion and visual/motion verification. Its Expo/native stack prescriptions do not replace the existing Next.js product. No Appllama MCP connection or paid account was used.
- [Libraries.dev Thinking Orbs](https://libraries.dev/orbs): thinking-orbs 0.3.1 supplies the decorative connecting state for actual loading. Installed type definitions use `theme`, so implementation follows that real API. Text remains authoritative; no generation state is fabricated. Animation pauses for reduced motion and hidden tabs.
- [Smashing Magazine safe triangles](https://www.smashingmagazine.com/2023/08/better-context-menus-safe-triangles/) and [Radix dropdown documentation](https://www.radix-ui.com/primitives/docs/components/dropdown-menu): the quick-creation menu uses the maintained Radix 2.1.24 pointer-grace area for nested workspace choices, keyboard navigation, Escape and touch, instead of hover-only navigation. Entries navigate to existing Guided and Free routes.

The hero moves through slow transform/opacity layers and has an explicit pause button. System reduced motion, hidden tabs and off-screen visibility stop movement. Authentication controls and evidence do not animate for decoration. Hero art is clearly labeled conceptual AI artwork and is not represented as a customer production artifact or source evidence.
