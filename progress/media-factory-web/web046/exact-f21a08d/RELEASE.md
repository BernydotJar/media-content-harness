# WEB046 — Review UX V15 release

Exact deployed SHA: `f21a08da32e4803b5aa93bab3e40a895cefbfde2`
Public URL: `https://media-factory.textilesdemedellin.com`

V15 replaces the review dashboard experience with a decision-first surface:
- media is the visual protagonist;
- one primary approval action;
- change request is secondary;
- Studio is optional and separate;
- Audio Finishing lives only in Studio;
- review authority is explained behind progressive disclosure rather than with internal policy labels;
- technical identifiers, provenance, evidence and stages remain available under `Más información`;
- blocked/recovery flows keep explicit operational guidance.

No server-side approval, tenant, audio, release or publication authority was widened. Publication remains separate and non-automatic.
